# General projection algorithm and provenance

Authority: Lean68218e876d2a38b1985b8590fff244a83c321783,
`type_checker.cpp:infer_proj`221–264, `reduce_proj_core`359–374 and

Inference first infers and WHNFs the projected term's type, verifies the encoded
family symbol, a checked inductive with exactly one constructor and complete
parameter/index arity. It universe-instantiates that checked constructor type,
WHNFs and instantiates every declared parameter, then traverses preceding fields.
When a remaining body contains loose BVars, substitute the corresponding earlier
projection; if the major type is Prop, that earlier field must also be Prop.
The selected field domain is returned only if it is Prop when the major is Prop.
Unused non-Prop earlier fields are skipped exactly as in the pinned source.
Binder, family, parameter, index and field counts remain data. Scope/type/reduction
services are the same services used by declarations and ordinary expressions.

Reduction WHNFs the major, recognizes a checked constructor by its environment
kind, and selects argument[nparams+projectionIndex] if present. It preserves the
caller's pending application stack and resumes WHNF on success. An unavailable
String-literal constructor preparation must GAP; a neutral/undersaturated major
returns no reduction. The reducer does not invent a check of the projection's
encoded family name: the pinned reduction relies on its separate typing rule.

The weighted family-count query must use checked provenance. Committed families
resolve via the original-block origin registry. Current private families resolve
via the counted, checked header prefix while a typing overlay is active, including
restored copies of those same header symbols during final rechecking. No raw
block can supply ownership/count approval. Recursor/constructor constants do not
become family owners. Returned family metadata combines the model-derived count,
checked index count and checked raw-family pointer.

Implementation after f5bb04d connects `projection_rules.py` through the source
inference and WHNF services. Family/constructor information in the independent
SPEC is generated by admission and published with its original block; native
input packing still supplies syntax only. Task-owned immutable frames retain
all live projection data across recursively invoked inference/reduction. Legacy
Boolean phase handlers are excluded from these owned return frames, including
phases that numerically alias old handlers.
